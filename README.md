DipSnap — a mean-reversion dip-buy paper trader for pump.fun. It never chases a spike: it waits for a fresh coin to fall 12–35% off its rolling peak and bounce at least 3% off its trough, buys the dip with a 0.15 SOL stake, and exits on a tight −10% stop-loss, a +18% take-profit, or a stale-position timeout. Paper trading only — the replay uses market data, never real funds.

## Run it

```sh
node main.ts
```
